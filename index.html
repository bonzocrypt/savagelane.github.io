VaultMyBag

Private collection management, resale intelligence, and digital records.

Live on the web. Android and iOS applications in testing.

I lead product development and technical operations for VaultMyBag through Vaulted Holdings LLC. As a joint owner and product engineering lead, my work spans application development, architecture, cloud administration, integrations, testing, deployment, and mobile release management. The product has also involved contractor contributions at different stages.

Built with React, TypeScript, and Vite, the application combines detailed handbag records, photos, supporting documents, collection analytics, community features, and private sharing. Firebase Authentication manages identity, Firestore stores operational data, and Firebase Storage handles uploaded files. Cloud Functions support backend workflows, while BigQuery supports larger product and resale datasets.

Private sharing required coordinating authentication, invitations, expiration, and database permissions. Recipients can accept an invitation without subscribing and access the records shared with them. Administrative authorization and storage rules provide additional controls over customer information. I also manage cloud access through Google Cloud IAM and handle sensitive credentials through Secret Manager.

The valuation system combines automated research with administrative review. Comparable sales, accepted and rejected results, internal notes, and pricing decisions persist across sessions before a finished Vaulted Estimate is published. Stripe supports subscriptions and individual purchases, with payment state connected to the features each customer can access.

I integrated PostHog, GA4, and Microsoft Clarity to understand navigation, feature usage, and signup problems. Mobile distribution work includes Google Play testing and Apple TestFlight, alongside authentication configuration, subscription setup, and release preparation.

Technology: React, TypeScript, Vite, Firebase, Google Cloud, BigQuery, Stripe, PostHog.

Kalshi Time & Sales

From trading automation to live market intelligence.

Android and iOS applications in testing. Built from practical trading automation and research.

My automation work began with Coinbase trading scripts, followed by a bot that traded BTC prediction markets on Kalshi. Developing those systems involved collecting and analyzing market data, managing order execution, reconciling positions, and building controls for loss limits, emergency stops, and recovery after interruptions.

That research led to Kalshi Time & Sales, a mobile application built with React Native, Expo, and TypeScript. It brings market listings, Level 2 order book data, individual trades, trade aggressor interpretation, and risk calculations into a dedicated market analysis interface.

REST APIs and WebSocket feeds connect the application to market data. RSA authentication supports API access, and SQLite provides local data storage. The development work connects my active trading background with data collection, execution systems, and the design of tools for understanding live prediction markets.

Technology: React Native, Expo, TypeScript, REST APIs, WebSockets, SQLite, RSA authentication.

EventPricing

Event discovery, ticket intelligence, and mobile delivery.

Live on the web and Android.

I developed EventPricing to help people discover events, track favorites, and find presale and ticket information. The platform combines browsing by location and category with event detail pages, alerts, and administrative review tools.

The current web application uses Next.js, React, TypeScript, Firebase, and Firestore. Event ingestion and source normalization turn information from different sources into consistent records. Visibility controls support review before publication, while canonical URLs, metadata, and structured event data make individual events discoverable through search.

Capacitor packages the application for Android, connecting the web product with mobile functionality and Google Play distribution. Analytics through GA4, Google Tag Manager, and Microsoft Clarity support navigation and conversion analysis across the product.

Technology: Next.js, React, TypeScript, Firebase, Firestore, Capacitor, Google Play.

BNZO

A Solana token proof of concept and launch infrastructure.

Historical blockchain development project.

I created and released BNZO on Solana, working with the Solana CLI and SPL Token tooling in a Windows and Ubuntu WSL development environment. The work included local validator testing, token minting, RPC connections, and remotely hosted metadata for wallet and explorer display.

I developed custom JavaScript and Rust tooling for Metaplex metadata operations, working with program derived addresses and update authorities. Resolving incompatible Rust, Solana, and Borsh dependencies required inspecting dependency trees, pinning versions, and separating projects into independent workspaces. I also compiled Metaplex CLI tooling from source.

The early HELLSBELLS token provided a live test of the launch infrastructure, including Raydium liquidity, Jupiter discovery, and public pages with blockchain explorer and market data integration. The project brought together blockchain tooling, metadata management, liquidity mechanics, web development, and launch lifecycle management.

Technology: Solana, SPL Token, Rust, Cargo, JavaScript, Node.js, Metaplex, Raydium, Jupiter.
